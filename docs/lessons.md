# Lessons Learned — PySortifyCLI

## 1. สิ่งที่ได้เรียนรู้จากการทำโครงงาน
* **การวางโครงสร้างฟังก์ชันให้ชัดเจน:** การแยกงานออกเป็นฟังก์ชันย่อยๆ เช่น การสแกนไฟล์ การตรวจสอบชื่อซ้ำ การย้ายไฟล์ การทำ Undo และการสรุปรายงาน ช่วยให้ไล่โค้ดง่ายและแก้บั๊กได้ตรงจุดมากขึ้น
* **ความสำคัญของการดักจับข้อผิดพลาด (`try / except`):** ในการใช้งานจริงมักเจอทั้งไฟล์หาย ไฟล์ JSON เสีย หรือผู้ใช้กรอกเมนู/ตัวเลือกไม่ตรงรูปแบบ การดัก error ให้เหมาะสมช่วยให้โปรแกรมไม่ล่มกลางคัน
* **การจัดการไฟล์และชื่อซ้ำ:** การย้ายไฟล์จริงด้วยโมดูลมาตรฐานของ Python ต้องระวังเรื่องการเขียนทับไฟล์เดิมและ encoding ของข้อความ โดยเฉพาะเมื่อมีไฟล์ชื่อเดียวกันซ้ำกันหลายรอบ
* **การทำงานร่วมกับ AI อย่างมีสติ:** AI ช่วยเร่งความเร็วในการร่างโครงโค้ดและชี้จุดทดสอบได้มาก แต่ต้องรันทดสอบจริงและอ่านโค้ดเองทุกบรรทัด เพราะบางครั้ง AI ให้โค้ดที่ทำงานได้เฉพาะกรณีพื้นฐาน เช่น ดักชื่อซ้ำได้แค่ชั้นเดียวหรือไม่ดักกรณีไฟล์เสีย

## 2. ข้อจำกัดของระบบในปัจจุบัน
* **ทำงานแบบ CLI บนเทอร์มินัลเท่านั้น:** ยังไม่มีหน้าจอ GUI หรือเว็บอินเทอร์เฟซ
* **จัดหมวดหมู่ตามนามสกุลไฟล์เป็นหลัก:** ยังไม่ได้วิเคราะห์เนื้อหาภายในไฟล์หรือจัดกลุ่มตามวันที่สร้าง/แก้ไขไฟล์แบบละเอียด
* **รองรับเฉพาะโฟลเดอร์ระดับที่เลือก:** ยังไม่ได้ทำโหมดสแกนโฟลเดอร์ย่อยแบบซ้อนหลายชั้น (recursive) อย่างเต็มรูปแบบ

## 3. แนวทางต่อยอดหากมีเวลาเพิ่ม
* เพิ่มคำสั่งตั้งค่าหรือแก้ไขกติกาหมวดหมู่นามสกุลไฟล์ผ่านเมนู CLI โดยตรงโดยไม่ต้องแก้ไฟล์ `categories.json` เอง
* เพิ่มตัวเลือกจัดกลุ่มไฟล์ตามช่วงเวลา (เช่น แยกโฟลเดอร์ตามปี/เดือน) หรือกรองตามขนาดไฟล์
* เพิ่มโหมดบันทึก log การทำงานแยกตามวันเวลา เพื่อช่วยตรวจสอบย้อนหลังได้ละเอียดขึ้น
