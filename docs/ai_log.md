| #1 | อยากได้ไอเดียโปรแกรม CLI ที่ใช้งานได้จริง ไม่เอาแบบซับซ้อนเกิน | เสนอตัวจัดระเบียบไฟล์ตามนามสกุล (PySortifyCLI) มีสแกน ดูตัวอย่าง ย้ายไฟล์ ย้อนกลับ และออกรายงาน | ตรงโจทย์และมีไฟล์จริงให้เทสต์ ไม่ใช่แค่เมนูหลอกๆ | ถูก | เลือกหัวข้อนี้และปรับฟีเจอร์ให้พอดีกับเวลาทำ | ได้กรอบงานที่ทำจบได้จริง |
| #2 | ช่วยวางโครงสร้างฟังก์ชันกับรูปแบบข้อมูลเก็บหมวดหมู่และประวัติ | แยกฟังก์ชันตามงาน ใช้ `categories.json` เก็บกติกา และ `history.json` เก็บประวัติการย้าย | แยกงานแต่ละส่วนชัด ไล่โค้ดง่ายขึ้นเยอะ | ถูก | เปลี่ยนชื่อฟังก์ชันและตัวแปรให้ตรงกับสไตล์ตัวเอง | โค้ดอ่านง่ายและคืนค่าได้ตามที่วางไว้ |
| #3 | ขอโค้ดย้ายไฟล์ลงโฟลเดอร์หมวดหมู่และกันชื่อซ้ำ | ใช้ `shutil.move` และเช็ก `os.path.exists` แค่ครั้งเดียวก่อนเติม `_1` | ชื่อซ้ำครั้งแรกไม่มีปัญหา แต่พอมีซ้ำอีกทีมันชนกันแล้วเออเรอร์ | ผิด (กันซ้ำได้แค่รอบเดียว) | แก้เป็นลูป `while os.path.exists(...)` นับ `_1`, `_2` ไปเรื่อยๆ จนไม่ซ้ำ | ย้ายไฟล์ซ้ำหลายรอบได้โดยไม่ทับของเดิม |
| #4 | ขอวิธีอ่านและเขียนไฟล์ JSON แบบปลอดภัย | เขียน `with open(..., encoding="utf-8")` และ `json.load` ตรงๆ ไม่มี `try/except` | ลองลบ `categories.json` หรือแก้ให้ JSON เสีย โปรแกรมเด้ง error แล้วปิดเลย | ผิด (ไม่ดักไฟล์หายหรือไฟล์เสีย) | เติม `try / except (FileNotFoundError, json.JSONDecodeError)` แล้วคืนค่า default แทน | ไฟล์หายหรือไฟล์เสียแล้วรันใหม่ โปรแกรมไม่ล่ม |

| #6 | ขอวิธีทำ Undo ย้ายไฟล์กลับที่เดิมและลบโฟลเดอร์หมวดหมู่ที่ว่าง | ย้ายไฟล์ล่าสุดกลับต้นทางตามประวัติ แล้วใช้ `os.rmdir` ลบโฟลเดอร์ปลายทาง | คืนไฟล์ได้ แต่ถ้าโฟลเดอร์ยังไม่ว่างจะฟ้อง error ตอนลบ | ถูก (ต้องระวังตอนลบโฟลเดอร์) | เช็กเงื่อนไขก่อนลบและครอบ `OSError` กันโปรแกรมค้าง | ย้อนกลับไฟล์ได้ครบและไม่พังตอนลบโฟลเดอร์ |
